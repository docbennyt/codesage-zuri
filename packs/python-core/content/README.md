# Python Core source content

The runtime `.zpk` pack is generated locally by Zuri as a SQLite + FTS5 file from the curated entries embedded in `crates/zuri-core/assets/python_core.json`.

The original `white_byte.py` dictionary was not retained as executable knowledge. Its useful concepts (variables, operators, conditionals) were rewritten as source-backed editorial summaries instead of being silently promoted to authoritative data.
